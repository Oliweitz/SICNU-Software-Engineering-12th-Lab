# 环境配置说明

> 软件工程课程设计 · 2026-09-13(更新)
> 配套文档:[技术方案.md](./技术方案.md)、[代码规范.md](./代码规范.md)、[Git工作流与提交规范.md](./Git工作流与提交规范.md)

## 1. 环境要求

| 项 | 版本要求 | 说明 |
|---|---|---|
| JDK | 17+(建议 21 LTS) | 编译目标 Java 17(pom 中 `--release 17`),更高版本同样兼容 |
| Maven | 3.9+ | 依赖下载建议配置国内镜像(见第 6 节) |
| MySQL | 8.x(必需) | 初始化脚本 `docs/init.sql`(建库 + 建表 + 种子数据) |
| Node.js | 20 LTS+(采用 Vue 前端时必需) | 见 3.2 |
| Redis | 可选 | 题目技术要求包含;可先用内存缓存代替,后期按需引入 |
| IDE | IntelliJ IDEA / VS Code | 需启用 Lombok 注解处理 |

快速验证:

```bash
mvn -version    # 确认 JDK 17+、Maven 3.9+
mvn test        # 工程编译 + 单元测试通过
```

## 2. 协作环境配置(clone 仓库后必做)

```bash
# 提交信息校验钩子(格式错误会被拒绝提交)
git config core.hooksPath .githooks

# 换行符策略(Windows 开发防 CRLF 污染)
git config core.autocrlf input

# 提交信息模板
git config commit.template .gitmessage
```

## 3. 组件安装指引

### 3.1 MySQL 8.x(必需)

- 安装包:https://dev.mysql.com/downloads/installer/ (MySQL Installer,选 Server only)
- 绿色版/免安装版也可;记下 **root 密码**和端口(默认 3306)
- 初始化时执行 `docs/init.sql`(建库 `ai_trial_platform` + 建表 + 种子数据)

### 3.2 Node.js 20 LTS +(采用 Vue 前端时必需,推荐)

- 下载:https://nodejs.org/zh-cn (选 LTS)
- 国内加速(建议):

```bash
npm config set registry https://registry.npmmirror.com
```

- 验证:`node -v`、`npm -v`

### 3.3 Redis(可选,题目技术要求包含)

- 用途:登录验证码、热点数据缓存
- 可先用内存缓存代替(技术方案已标注可选),需要时再引入
- 安装方式:Windows 版 Redis 或 Docker 容器

### 3.4 对象存储(可选)

- 默认用**本地磁盘目录**模拟(无需额外组件);未来可替换 MinIO

## 4. 项目结构说明

```
软件工程项目/
├── pom.xml              # 后端 Maven 工程(根,依赖版本统一声明)
├── README.md            # 项目说明与快速开始
├── .gitignore           # 忽略规则
├── .gitattributes       # 换行符策略
├── .editorconfig        # IDE 统一设置
├── .githooks/           # 提交信息校验钩子
├── docs/                # 技术方案、环境配置、代码规范、Git 规范、init.sql
├── src/                 # 后端 Java 代码(common/config 基础层)
└── frontend/            # Vue 3 前端工程(迭代 3 引入,独立 npm 工程)
```

## 5. 一键启动流程(目标)

```bash
# 1. 初始化数据库(首次)
mysql -u root -p < docs/init.sql

# 2. 启动后端(8080),在仓库根目录执行
mvn spring-boot:run

# 3. 启动前端(5173,开发模式)
cd frontend && npm install && npm run dev

# 4. 浏览器访问 http://localhost:5173
```

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 依赖下载慢 | Maven 配置阿里云镜像(settings.xml 中将 central 镜像指向 `https://maven.aliyun.com/repository/public`);npm 用 npmmirror(见 3.2) |
| 端口 8080 / 3306 被占用 | 改 `application.yml` 中端口;查占用 `netstat -ano | findstr 8080` |
| 中文乱码 | 工程统一 UTF-8(pom 中 `project.build.sourceEncoding`);MySQL 连接串加 `characterEncoding=utf8`;IDE 设置 UTF-8 |
| JDK 版本问题 | 项目编译目标 Java 17,开发机 JDK 须为 17+;21/24 等更高版本同样兼容 |
| 提交被钩子拒绝 | 提交信息格式不符,按提示修改;规范见 Git工作流与提交规范.md 第 3 节 |
| `mvn spotless:check` 失败 | 先执行 `mvn spotless:apply` 格式化后再提交 |

Maven 镜像配置示例(`~/.m2/settings.xml`,仅需配置一次):

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <name>Aliyun Central Mirror</name>
      <url>https://maven.aliyun.com/repository/public</url>
      <mirrorOf>central</mirrorOf>
    </mirror>
  </mirrors>
</settings>
```
