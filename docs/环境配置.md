## 2. 协作环境配置(clone 仓库后必做)

```bash
# 提交信息校验钩子(格式错误会被拒绝提交)
git config core.hooksPath .githooks

# 换行符策略(Windows 开发防 CRLF 污染)
git config core.autocrlf input

# 提交信息模板
git config commit.template .gitmessage
```

## 3. 需新增的环境

### 3.1 MySQL 8.x(必需)

- 安装包:https://dev.mysql.com/downloads/installer/ (MySQL Installer,选 Server only)
- 绿色版/免安装版也可;记下 **root 密码**和端口(默认 3306)
- 项目初始化时执行 `init.sql`(已提供:建库 `ai_trial_platform` + 建表 + 种子数据)

### 3.2 Node.js 20 LTS +(采用 Vue 前端时必需,推荐)

- 下载:https://nodejs.org/zh-cn (选 LTS)
- 国内加速(必做):

```bash
npm config set registry https://registry.npmmirror.com
```

- 验证:`node -v`、`npm -v`

### 3.3 Redis(可选,题目技术要求包含)

- 用途:登录验证码、热点数据缓存
- 本机安装不便时可先不装:方案文档已说明为可选,用内存缓存代替,答辩时说明
- 需要时下载 Windows 版 Redis 或使用 Docker

### 3.4 对象存储(可选)

- 默认用**本地磁盘目录**模拟(免部署);未来可替换 MinIO

## 5. 一键启动流程(目标)

```bash
# 1. 初始化数据库(首次)
mysql -u root -p < docs/init.sql

# 2. 启动后端(8080)
cd 软件工程项目 && mvn spring-boot:run

# 3. 启动前端(5173,开发模式)
cd frontend && npm install && npm run dev

# 4. 浏览器访问 http://localhost:5173
```

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 依赖下载慢 | Maven 阿里云镜像已配置;npm 用 npmmirror(见 3.2) |
| 端口 8080 / 3306 被占用 | 改 `application.yml` 中端口;查占用 `netstat -ano | findstr 8080` |
| 中文乱码 | pom 已设 UTF-8;MySQL 连接串加 `characterEncoding=utf8`;IDEA 设置 UTF-8 |
| JDK 版本问题 | 项目目标 Java 17,JDK 24 编译没问题(已验证);若换环境需 JDK 17+ |
| 提交被钩子拒绝 | 提交信息格式不符,按提示修改;规范见 Git工作流与提交规范.md 第 3 节 |
| `mvn spotless:check` 失败 | 先执行 `mvn spotless:apply` 格式化后再提交 |
